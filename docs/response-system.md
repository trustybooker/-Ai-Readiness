# Response System

Use these scripts to respond consistently. Replace bracketed placeholders manually. Do not promise jobs, revenue, accreditation, or legal compliance.

## Sales rule

Every reply should do three things:

1. Help the person feel understood.
2. Recommend one clear next step.
3. Make it easy to act now without pressuring them into the wrong offer.

The best sale is the smallest useful step that moves the person forward.

## Team or implementation response

This looks like a higher-touch team or implementation opportunity. The right move is a short discovery review before payment so scope, risk, budget, and timeline are clear.

Ask for:

1. Business type.
2. Team size.
3. Main workflow problem.
4. Existing tools.
5. What success should look like in 30 to 60 days.

Then recommend the audit, team sprint, or implementation project.

Clear close:

If the workflow is ready, we can move into a Team Training Sprint or Implementation Review. If the workflow is unclear, the audit should come first.

## Follow-up cadence

- Same day or next business day: respond with the correct path.
- Day 3: follow up with one clear action.
- Day 7: ask if they want the score interpreted or want the request closed.
- Day 14: close the lead if there is no reply.

## Friction reducers

Use these when a lead is uncertain:

- Start with the free checklist.
- Offer a short review before payment.
- Explain exactly what is included.
- Explain what is not included.
- Recommend the starter path if the larger offer is too much.
- Offer the Lab if they need ongoing support but not custom implementation.

## Closing script
