# Skill Registry and Reminder List

This is the active skill list for the AI Kollege platform. Update this file whenever a new skill is added or strengthened.

## Daily reminder brief

Audit first. Use the Winning Skill, Boss Skill, and World Skill together. Start with the real painful problem, not the gold. No fake claims. Keep Jesus-centered integrity, Solomon-level wisdom, customer love, loyalty, truth, proof, delivery, and revenue discipline together. Do not call the project production-ready until live tests pass. Ask whether any new skills were added and update this registry before continuing.

## Skill quality standard

Every skill must include:

1. Clear purpose.
2. When to use it.
3. What it protects against.
4. A step-by-step operating sequence.
5. A proof or validation standard.
6. A handoff/output format.
7. A no-fake-claims boundary.
8. A problem-first filter.
9. A customer-fruit measure.
10. A next-action rule.

Weak skills only describe a role. Strong skills change decisions, prevent mistakes, and produce a usable output.

## Skill update protocol

When Orrett adds or upgrades a skill:

1. Add or update it in this file with an icon.
2. Explain what it does in plain language.
3. Explain when to use it.
4. Explain what weakness it prevents.
5. Define its output format.
6. Update the daily reminder brief if the skill affects project-wide behavior.
7. Update related docs or validation only if the skill becomes a required project artifact.
