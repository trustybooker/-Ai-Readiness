## Skill update protocol

When Orrett adds a new skill:

1. Add it to this file with an icon.
2. Explain what it does in plain language.
3. Explain when to use it.
4. Update the daily reminder brief if the new skill should be included.
5. Update related docs or validation only if the skill becomes a required project artifact.
